🚀 Hands-On Workshop Preparation

Environment Setup Checklist

Complete these steps on your laptop before coming to tomorrow's session!

Windows Setup
1
Install Git:
Download from git-scm.com and install.
2
Install Python 3.10+:
Download from python.org.
⚠️ MUST check: "Add python.exe to PATH"
3
Enable WSL 2 (Required for Docker):
Open PowerShell as Admin and run:
wsl --install
💡 Restart laptop after running command
4
Install Docker Desktop:
Download from docker.com and launch it.
Linux Setup
1
Git & Python:
sudo apt update
sudo apt install -y git python3 python3-pip
2
Docker Engine:
sudo apt install -y docker.io
sudo usermod -aG docker $USER
3
Permissions:
Log out & log back in to apply group privileges.

✅ Final Verification Step

Run this in Terminal or PowerShell to confirm Docker is working:

$ docker run hello-world
