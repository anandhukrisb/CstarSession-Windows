💻 Hands-On Student Exercises

Workshop Challenge & Tasks Sheet

Follow along during the session and complete the 3 core tasks below.

Task 1: Clone & Trigger the App Crash
Phase 1 — The Problem

Clone the starter repository and run the application locally on your host OS without Docker.

  • Clone the repo: git clone https://github.com/anandhukrisb/CstarSession-Windows.git
  • Set up virtual environment and install dependencies from requirements.txt.
  • Start Flask app (python app.py) and open http://localhost:5000 in your browser.
  • Click "Generate Summary Report" on the web UI and note down the exact error traceback on your terminal!
Task 2: Write Your First Dockerfile
Phase 2 — Containerization

Create a file named Dockerfile in the project root to package the app into a portable Linux container.

  • Use python:3.10-slim as the base image.
  • Set working directory to /app and copy requirements.txt.
  • Run pip install -r requirements.txt.
  • Copy the rest of the application files into /app.
  • Expose port 5000 and set command: CMD ["python", "app.py"].
Task 3: Build & Run the Container
Phase 3 — The Solution

Build your Docker image and run it on port 5000 to verify that Docker fixed the crash.

  • Build image: docker build -t log-report-app .
  • Run container: docker run -p 5000:5000 log-report-app
  • Refresh http://localhost:5000, click "Generate Summary Report", and verify that it succeeds!
🎯 Target Goal: Every participant successfully runs the app inside Docker with 0 errors!
